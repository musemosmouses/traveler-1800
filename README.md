## The entry

> The internet is a road of light joining every post office and library on earth, so a letter you send arrives before the ink dries.

130 characters, one sentence. It names the internet, then explains it with
only things a person from 1800 already knows — a road, a post office, a
library, a letter, ink — in a single comparison (a road of light) that is
true of the internet as it is now: messages cross the world in under a
second, carried as light through glass threads under the sea and land.
